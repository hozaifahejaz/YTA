# Bundled fonts

All fonts here come from the Google Fonts repository (github.com/google/fonts) and are licensed under the SIL Open Font License 1.1. Each folder holds the font and its `OFL.txt`. They are bundled so brand artwork (profile pictures, banners, thumbnails) can be drawn with them and the result used freely, including commercially.

Inter, Manrope, DM Sans, Space Grotesk, Outfit, Sora, Archivo, Archivo Black, Oswald, Bebas Neue, Anton, Fraunces, Playfair Display, DM Serif Display, Lora.
